# DSP32-Core
![](https://github.com/Fihdi/DSP32-Core/blob/main/dsp32-core1.png?raw=true)
![](https://github.com/Fihdi/DSP32-Core/blob/main/dsp32-core2.png?raw=true)

DSP32-Core is a small (4cm x 2cm) audio development board based on the ESP32-S3. This board can be used as the core for digital music and audio applications involving synthesizers, samplers, digital effects, sequencers, etc. The SPI interface allows to connect an SD-card to the board and save and replay music and project settings.

# Features
+ Stereo audio in- and output
+ 3.3V and 5V voltage regulator
+ USB and SPI Interface
+ up to 15 GPIO pins
+ PCM1808 ADC
+ PCM5102 DAC.
